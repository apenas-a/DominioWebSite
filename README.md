# Domínio Fundição — Website

Este repositório contém a aplicação web institucional da **Fundição Domínio**. O projeto é uma SPA (Single Page Application) moderna desenvolvida com foco em performance, responsividade e consistência visual para apresentação de ligas metálicas, processos produtivos e catalogação de peças industriais.

---

## 🛠️ Tecnologias Principais

- **Frontend:** React 18, TypeScript, Vite
- **Estilização:** Tailwind CSS v3, Radix UI Primitives, Lucide Icons
- **Roteamento:** React Router DOM v6
- **Gerenciamento de Estado/Queries:** TanStack Query v5 (React Query)
- **Animações:** Framer Motion

---

## 🚀 Inicialização Local

O projeto oferece suporte a gerenciadores de pacotes populares como **npm** e **Bun**.

### Pré-requisitos
Certifique-se de ter o [Node.js](https://nodejs.org/) (ou [Bun](https://bun.sh/)) instalado em sua máquina.

### Passo a Passo

1. **Clonar o repositório:**
   ```bash
   git clone https://github.com/apenas-a/DominioWebSite.git
   cd DominioWebSite
   ```

2. **Instalar dependências:**
   ```bash
   # Utilizando npm
   npm install

   # Ou utilizando Bun
   bun install
   ```

3. **Iniciar servidor de desenvolvimento:**
   ```bash
   # Utilizando npm
   npm run dev

   # Ou utilizando Bun
   bun run dev
   ```
   *O site estará disponível por padrão em `http://localhost:5173/`.*

4. **Compilar para produção (Build):**
   ```bash
   npm run build
   # ou
   bun run build
   ```
